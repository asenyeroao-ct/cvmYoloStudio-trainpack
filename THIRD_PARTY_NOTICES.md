# Third-party components

`ul_bridge` imports the following packages at run time. They are not part of this repository or of its
release zip; they are installed separately into the same Python environment.

|---|---|---|
| Ultralytics | AGPL-3.0 | https://github.com/ultralytics/ultralytics |
| PyTorch (`torch`) | BSD-3-Clause | https://github.com/pytorch/pytorch |
| torchvision | BSD-3-Clause | https://github.com/pytorch/vision |
| NumPy | BSD-3-Clause | https://github.com/numpy/numpy |
| OpenCV (`opencv-python-headless`) | Apache-2.0 (MIT for the Python packaging) | https://github.com/opencv/opencv-python |

Each package is distributed under its own license; see the package's own files for the full text.
